# Launch Post Copy

One-liner: Route any model. Prove every dollar.

XFuel is the verifiable settlement and payments layer for AI compute. Agents submit inference, settle in USDC via x402 on Base, and get a shareable receipt (`verify_url`). Tier 1 signed by default; Tier 2 SP1 settlement proof on demand. Tier 2 attests settlement metadata + output commitment — not black-box model correctness.
