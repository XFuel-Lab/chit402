## Shape

Equity-first raise: SAFEs in USDC with a token warrant / side letter for pro-rata XF at TGE. Staged and token-light — fee-collecting business + optional buyback policy, not a yield token.

1. Equity-first (SAFE + warrant)
2. USDC denomination (matches Base revenue)
3. Staged gates (pre-seed → seed → later community token round)
4. Token-light narrative

- Pre-seed → Seed: Base verifier live, first real USDC settlement E2E, audit engaged, entity formed
- Seed → Community: completed audit, meaningful volume, counsel-reviewed tokenomics
