# Escrow contract tests (Foundry)

Tests, vectors and a deploy script for `contracts/escrow/EquivocationEscrowV0.sol`.
The contract source stays under `contracts/` so the repo Hardhat build compiles it too.

```
cd test/escrow
forge test                     # everything except the fork test
forge test --gas-report        # with per-function gas
BASE_SEPOLIA_RPC_URL=https://sepolia.base.org forge test --mc ForkBaseSepoliaTest -vv
```

Needs `node_modules/@openzeppelin/contracts` at the repo root (`npm ci`). There is no
forge-std submodule: `t/utils/Test.sol` holds the small cheatcode interface and assertions.
`evm_version = "osaka"` makes the local EVM serve the EIP-7951 P256VERIFY precompile at
`0x100` with the Base Azul rules (6,900 gas, empty output on failure).

## Layout

| Path | What |
|---|---|
| `t/Escrow.t.sol` | C1-C9, C12, C14-C25 |
| `t/Merkle.t.sol` | C10 (gateway JS vectors vs Solidity), C11 (fuzzed malformed proofs) |
| `t/CommitReveal.t.sol` | CR1-CR14 |
| `t/Binding.t.sol` | BC1-BC10 |
| `t/EdgeCases.t.sol` | Extra edge cases and a payout bound fuzz |
| `t/IncidentScope.t.sol` | One incident per (epoch, kid): no re-freeze or second payout from a settled fork, a new epoch opens its own incident |
| `t/Precompile.t.sol` | Local 0x100 against a Wycheproof P-256 subset and edge cases |
| `t/Vectors.t.sol` | Constants, the worked head vector, the production kid thumbprint, node-signed vectors |
| `t/ForkBaseSepolia.t.sol` | F1, opt-in: read-only Base Sepolia fork and `eth_call` to 0x100 |
| `vectors/*.json` | Shared vectors (also meant for the gateway fixed-head and binding tests) |
| `gen-vectors.mjs` | Rebuilds the vectors from gateway code; `--check` verifies them |
| `script/DeployEquivocationEscrowV0.s.sol` | Deploy script. Not run. Reads every input from the environment |

## Fork test (F1)

Skipped unless `BASE_SEPOLIA_RPC_URL` is set. It forks Base Sepolia read-only, checks that
Circle USDC `0x036CbD53842c5426634e7929541eC2318f3dCF7e` has code, `decimals() == 6` and
symbol `USDC`, sends `eth_call` to `0x100` with a throwaway-key signature (valid, high-S,
tampered, r=0, s=n, off-curve, infinity) and a Wycheproof subset, and runs a type A
commit and reveal against an escrow deployed in the local fork only. No key is read and no
transaction is sent.

## Vectors

`node test/escrow/gen-vectors.mjs --check` (from the repo root, after `npm ci` in
`services/gateway`) rebuilds `eip712.json` and `merkle.json` from
`services/gateway/src/receipt-merkle.js` and checks the stored signatures with node crypto.
The throwaway key in `eip712.json` was generated by the script and its private half was
discarded. It is not the issuer key.
